# 🐴 HORSE WORLD

브라우저에서 즐기는 실시간 멀티플레이어 3D 말 오픈월드 게임입니다.

## 기능
- 닉네임 입력 후 입장
- Three.js 기반 3D 월드와 탑뷰 추적 카메라
- 초원, 숲, 호수, 사막, 설원 등 여러 지역
- Socket.IO 실시간 플레이어 동기화
- 전체 채팅 및 접속자 수
- 키보드와 모바일 터치 조작
- Render 배포 설정 포함

## 로컬 실행
Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 http://localhost:3000 접속합니다.

## 조작법
- `W A S D` 또는 방향키: 이동
- `Shift`: 달리기
- `Space`: 점프
- 마우스 드래그: 카메라 회전
- 마우스 휠: 카메라 줌
- 모바일: 화면 왼쪽 조이스틱, 오른쪽 버튼

## GitHub + Render 배포
1. 압축을 풀고 GitHub에 새 저장소를 만듭니다.
2. 프로젝트 파일 전체를 저장소에 업로드합니다.
3. Render에서 **New + → Web Service**를 선택하고 GitHub 저장소를 연결합니다.
4. 설정은 `Build Command: npm install`, `Start Command: npm start`로 지정합니다.
5. 배포가 완료되면 Render가 제공하는 `onrender.com` 주소로 접속합니다.

`render.yaml`이 포함되어 있어 Blueprint로도 배포할 수 있습니다.

## 참고
- 현재 플레이어 데이터는 서버 메모리에 저장됩니다. 서버가 재시작되면 접속자와 위치 데이터가 초기화됩니다.
- 계정/비밀번호 없이 닉네임만 사용하는 공개 테스트 버전입니다. 닉네임 중복 방지, 신고/차단, 영구 저장, 운영자 도구는 아직 포함되지 않았습니다.
- Three.js는 브라우저에서 CDN으로 불러옵니다. 첫 접속 시 인터넷 연결이 필요합니다.
